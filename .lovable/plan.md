## מטרה

1. להעביר את כל חוויית הפנסיה לפלטת הירוקים של המערכת (כיום סגול־כחול).
2. ליצור היררכיה ויזואלית ברורה בין **מסך הקטגוריה** (רשימת מוצרים) לבין **מסך המוצר הפנימי** — שני הקליפים יראו שונה לחלוטין כדי שלא יתבלבלו, ובניגוד למסכי הנכסים שבהם הקטגוריה והמוצר חולקים שפה זהה.

---

## פלטת הירוקים (תואמת ל-`IndexC` והמערכת)

```text
deep   = hsl(155, 60%, 22%)   ← ירוק כהה עמוק (היררכיה עליונה)
core   = hsl(150, 60%, 38%)   ← ירוק ראשי
fresh  = hsl(145, 65%, 48%)   ← ירוק רענן
mint   = hsl(150, 55%, 88%)   ← רקע פסטל
soft   = hsl(150, 35%, 96%)   ← surface בהיר
ink    = hsl(155, 40%, 12%)   ← טקסט כהה
muted  = hsl(150, 12%, 48%)   ← טקסט משני
```

הגרדיאנט הראשי של פנסיה:
`linear-gradient(160deg, hsl(155,60%,22%) 0%, hsl(150,60%,32%) 55%, hsl(145,65%,42%) 100%)`

## היררכיה ויזואלית — שני מסכים שונים

### מסך 1 — קטגוריית פנסיה (`/assets/pension`)
**זהות:** "Level 1" — נשארת בשפה של מסכי הקטגוריות (`CategoryPageC`) כדי לשמור על קונסיסטנטיות עם נכסים/התחייבויות/ביטוחים. רק החלפת ערכת הצבעים לירוק.

- gradient hero ירוק + KPI + פילטרים + רשימה + dana bubble.
- כל הסגול-כחול → ירוק (`theme.gradient`, `accent`, `accentBg`, `accentText`, `sheetShadow`, וטקסטי המחירים בטריילינג).

### מסך 2 — מוצר פנסיה פנימי (`/assets/pension/:id`)
**זהות:** "Level 2" — שפה ויזואלית **שונה לגמרי** ממסך הקטגוריה. במקום gradient hero מלא — מסך בהיר, ממוקד-נתונים, עם דגשי ירוק בלבד. זה מה שיוצר את ההפרדה.

מבנה חדש למסך המוצר:
```text
┌──────────────────────────────────────┐
│ רקע: hsl(150, 35%, 96%) (mint soft) │
├──────────────────────────────────────┤
│ Top bar דק לבן + breadcrumb:         │
│   ‹ פנסיה / קרן מקיפה מנורה          │
│   חזרה (chevron ירוק)                 │
├──────────────────────────────────────┤
│ Product header card (לבן עם accent  │
│  bar ירוק עבה משמאל):                │
│   [icon] קרן פנסיה מקיפה             │
│          מנורה · מסלול כללי          │
│   ₪842,300         צפי קצבה          │
│   צבירה            ₪7,200/ח          │
├──────────────────────────────────────┤
│ Tabs ירוקים: סקירה · ביצועים · דמ"נ │
│              · כיסויים               │
├──────────────────────────────────────┤
│ סקשנים לבנים על רקע mint, ללא       │
│ gradient hero. כל סקשן עם header דק │
│ וקו ירוק 2px בצד.                    │
├──────────────────────────────────────┤
│ Dana insight card — ירוק כהה        │
│ (gradient deep→core) עם avatar      │
├──────────────────────────────────────┤
│ Bottom chat bar (זהה למסכים אחרים)  │
└──────────────────────────────────────┘
```

ההבדלים המרכזיים מול מסך הקטגוריה:
| היבט | קטגוריה (Level 1) | מוצר (Level 2) |
|---|---|---|
| Hero | gradient ירוק מלא, עיגול אווטר | אין hero — top bar דק + product card לבן |
| רקע גוף | sheet לבן עם חצי-עיגול עליון | flat mint על כל המסך |
| הירארכיה | קטגוריה כותרת ענק | breadcrumb דק + שם מוצר |
| Tabs | פילטר chips אופקיים | tab bar אמיתי עם underline ירוק |
| Sections | רקע כללי לבן | כרטיסים לבנים עם accent-bar ירוקה מימין |
| צבע דומיננטי | ירוק (גרדיאנט) | לבן/mint + מבטאי ירוק |

זה יוצר תחושה ברורה של "ירדתי שכבה" במקום "החלפתי קטגוריה".

## פרטים טכניים

- כל הצבעים HSL inline (תואם לשאר הקובץ; אין tokens חדשים ב-`index.css`).
- אייקונים נשארים: `PiggyBank` / `Briefcase` / `Landmark` / `ShieldCheck`.
- `Sparkline` נשאר אך `color={core}` (ירוק).
- ל-tabs נשתמש ב-state מקומי `activeTab` שמחליף את ה-`Section`-ים המוצגים (סקירה = פרטי החיסכון, ביצועים = ביצועים+sparkline, דמ"נ = דמי ניהול, כיסויים = coverage).
- Dana card: `linear-gradient(135deg, hsl(155,60%,22%) 0%, hsl(150,60%,38%) 100%)`.
- ה-`InsightsSheetC` שנפתח מ-chat נשאר כפי שהוא (השפה שלו ניטרלית).
