# Signup2 — Full end-to-end onboarding

מסלול הרשמה מלא חדש שמשלב את כל שאלות הפרופיל יחד עם 3 מסכי הסכמה (פנסיה / ביטוח / אשראי), עם אופציה לדלג בכל שלב, טוסטים תומכים בין השאלות, ובסוף מוביל ל-`/aha2` במצב "אחרי חיבור" לפי מה שאושר.

## Route חדש
- `/signup2` ב-`src/App.tsx` → קומפוננטה חדשה `src/pages/Signup2.tsx`
- בכניסה ל-`/aha2` נקרא `location.state` כדי לדעת אילו חיבורים אושרו ולפתוח את הדשבורד במצב המתאים

## סדר המסכים (לפי בחירת המשתמש)

```
1.  טלפון
2.  קוד SMS
3.  שם פרטי + משפחה
4.  ✱ הסכמה — פנסיה (מסלול הרמוני)
5.  גיל
6.  מצב משפחתי
7.  ✱ הסכמה — ביטוח (קציר ביטוחים)
8.  תעסוקה
9.  מטרות
10. ✱ הסכמה — אשראי (BDI / נתוני אשראי)
11. מסך טעינה → /aha2
```

כל מסך שאלה (5–9) ממשיך עם auto-advance אם כבר קיים, אחרת CTA "המשך". כותרת עליונה: bar התקדמות רציף לאורך כל הזרימה (11 צעדים), כפתור חזור, וקישור "דלג" ימני.

## מסכי ההסכמה (4 / 7 / 10)

משתמשים ב-`ConsentAnnex` הקיים כפי שהוא + מוסיפים מעל ה-CTA **social proof callout** קטן (כרטיס 1 שורה, רקע soft, אייקון `Sparkles`/`TrendingUp`, טקסט bold קצר):

- **פנסיה:** "43% מהמשתמשים גילו כפל ביטוחים אחרי החיבור"
- **ביטוח:** "86% מהמשתמשים חסכו מעל ₪104,500 בשנה הראשונה"
- **אשראי:** "המשתמשים שלנו חסכו בממוצע ₪780 בחודש על המשכנתא"

תחתית כל מסך הסכמה:
- CTA ראשי "אשר וחתום" (disabled עד שמסומן ה-checkbox ב-`ConsentAnnex`)
- מתחתיו לינק טקסט קטן וענוג "דלג בינתיים" → ממשיך הלאה בלי לסמן את החיבור כפעיל

State לפי מסך: `{ pension: bool, insurance: bool, credit: bool }` נישא ב-`navigate("/aha2", { state: { connected: {...}, firstName } })`.

## טוסטים תומכים בין שאלות

שימוש ב-`sonner` (כבר מותקן). אחרי שלבים נבחרים נקפיץ הודעה קצרה, חמה, מהפרסונה של דנה (אווטר עגול):
- אחרי שם → "נעים להכיר, {שם} 👋"
- אחרי גיל → "מתאימים לך המלצות לשלב הזה ✨"
- אחרי תעסוקה → "יש זכויות שכדאי שתכיר/י 💡"
- אחרי מטרות → "מצוין, בונים תוכנית 🎯"

טוסט מותאם RTL, רקע לבן, צל רך, אייקון אווטר מימין; משך ~2.4s.

## מצב היעד ב-/aha2

`AhaDashboard2` יתחיל ב-`completed85=true` (כדי לדלג על הצ'אט) ויסמן את הקטגוריות שאושרו כ"מחוברות" — `assets/liabilities/insurance` בהתאם ל-`connected`. כרטיס פנסיה במרכז הפיננסי יראה נתונים מלאים אם `connected.pension`, אחרת dashed empty. זהה לביטוח/אשראי. אם דילגו על הכל — מצב פתיחה רגיל עם empty states.
