

## שינוי מיקום תמונת הרקע בגרסא ב׳

### מצב נוכחי
תמונת הטבע (`nature-bg.jpg`) ממוקמת בתוך הכרטיסייה הראשית בלבד, מה שמגביל את האפקט הזכוכיתי לגבולות הכרטיס.

### מה ישתנה
- תמונת הטבע תעבור לרקע של החלק העליון של המסך (מאחורי ה-header והכרטיסייה הראשית)
- תתווסף שכבת gradient שתגרום לתמונה לדעוך בהדרגה כלפי מטה (fade to background color)
- הכרטיסייה הראשית תישאר זכוכיתית עם `backdrop-filter: blur` -- כעת היא תטשטש את רקע המסך עצמו
- הדעיכה תסתיים לקראת אזור ההמלצות

### פרטים טכניים

**קובץ: `src/pages/IndexB.tsx`**

1. הוצאת תמונת הרקע מתוך הכרטיסייה והצבתה כ-`absolute` ברמת ה-container הראשי של הדף
2. הוספת שכבת `linear-gradient` שקופה-לאטומה מעל התמונה כדי ליצור את אפקט הדעיכה
3. הכרטיסייה הראשית תישאר עם אותם מאפייני זכוכית (`backdrop-filter`, שקיפות) אבל בלי תמונה פנימית

```text
+----------------------------------+
|  [תמונת טבע - רקע מלא]          |
|  [gradient fade overlay]         |
|  +----------------------------+  |
|  | כרטיסייה זכוכיתית (blur)   |  |
|  | RadialGauge + הסבר         |  |
|  +----------------------------+  |
|  ~~~~ דעיכה הדרגתית ~~~~        |
|                                  |
|  המלצות לשיפור (רקע רגיל)       |
+----------------------------------+
```
