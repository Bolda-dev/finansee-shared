
## גרדיינט סגול־כהה אחיד בכל גרסה B

קחי את האווירה של הכרטיס שצירפת — שחור עמוק שמתערבב לסגול עשיר עם נגיעת זוהר — ונעשה אותה לזהות הצבעונית הראשית של גרסה B. ה-CTAs יקבלו את הגרדיינט הזה (במקום הוורוד-סגול הזרחני הנוכחי), והכרטיסיות יקבלו ואריאציות הרמוניות באותה משפחה.

### 1. הגדרת "הגרדיינט המאסטר" (כמו ב-Overview)
גרדיינט לדוגמה שמשחזר את התחושה בתמונה:
```
linear-gradient(135deg,
  hsl(250, 35%, 8%) 0%,      /* שחור-סגלגל בפינה ימין-תחתונה */
  hsl(265, 45%, 18%) 35%,
  hsl(280, 60%, 38%) 70%,
  hsl(290, 75%, 58%) 100%    /* זוהר סגול בפינה שמאל-עליונה */
)
```
+ overlay עדין של `radial-gradient` לבן בשקיפות נמוכה כדי לחקות את ה"הילה" שרואים בכרטיס.

### 2. כפתורי CTA — שחור עם גרדיינט סגול
כל הכפתורים שכרגע משתמשים ב-`linear-gradient(135deg, hsl(285,75%,62%), hsl(310,70%,55%))` יוחלפו לגרדיינט המאסטר:
- כפתורי "בדוק עכשיו" / "פרטים" בכרטיסי המלצות
- כפתורי ה-+ (הוסף הכנסה / הוצאה / ביטוח)
- כפתור Send בבר הצ׳אט התחתון (`IndexB`)
- כפתור Send בתוך `InsightsSheet`
- בועיות הצ׳אט של המשתמש ב-`InsightsSheet`
- ה-pill של אחוז השינוי (1.8%+) ליד שווי נטו → יקבל מסגרת/רקע בטון תואם
- אנימציית ה-shimmer של שווי נטו (`networth-shimmer` ב-`index.css`) → תכוון לאותם גוונים סגולים-ורודים מהפלטה החדשה כדי שתיראה אחידה

הצל יהיה סגול עמוק במקום ורוד: `0 6px 18px hsla(265, 60%, 25%, 0.45)`.

### 3. שלוש הכרטיסיות (נכסים / התחייבויות / ביטוח) — ואריאציות הרמוניות
במקום ציאן-בהיר, אדום-ורוד וכתום-זהוב (שלא שייכים למשפחה), נחליף לשלוש ואריאציות באותה משפחת שחור→סגול, כל אחת עם הטיה אחרת כדי להבדיל ביניהן ויזואלית מבלי לשבור הרמוניה:

- **נכסים (חיובי):** הטיה לסגול-אינדיגו עם ניצוץ ויולט.
  `linear-gradient(135deg, hsl(245, 40%, 10%) 0%, hsl(260, 55%, 28%) 55%, hsl(275, 70%, 52%) 100%)`
  אייקון לבן, נקודת הדגש בויולט בהיר.

- **התחייבויות (סכנה):** הטיה לבורדו-סגול (שומר על "אזהרה" בלי לקפוץ מהפלטה).
  `linear-gradient(135deg, hsl(255, 35%, 9%) 0%, hsl(295, 50%, 25%) 55%, hsl(330, 65%, 50%) 100%)`

- **ביטוח (יציב):** הטיה לסגול-מלכותי עמוק.
  `linear-gradient(135deg, hsl(250, 40%, 8%) 0%, hsl(270, 55%, 22%) 55%, hsl(285, 65%, 45%) 100%)`

הצללים יותאמו לטון של כל כרטיס (`hsla(265-330, 60%, 25%, 0.4)`).
ה-ripples הלבנים השקופים נשארים — הם מוסיפים את אפקט ה-"הילה" של התמונה.
עיגולי האייקון נשארים לבנים, אך צבע האייקון בפנים יותאם לגוון הראשי של כל כרטיס (אינדיגו / מג׳נטה / סגול).

### 4. רקע, באדג׳ים וטקסטים מסביב
- ה-pill של "1.8%+" יעבור מטקסט סגול-ורוד עז (`hsl(290,70%,55%)`) ל-`hsl(275, 65%, 45%)` — אותה משפחה אבל עמוק יותר, כך שמתחבר לכרטיסים.
- טקסט החיסכון בכרטיסי ההמלצות (`• ₪1,800/שנה`) יעבור לאותו טון.
- ה-Sparkles והאייקונים הקטנים בכרטיסי ההמלצות (recIcons) יעברו ל-`hsl(275, 65%, 50%)`.
- רקע עיגול האייקון בכרטיס המלצה (`hsl(250, 50%, 95%)`) יישאר אבל יוסט מעט ל-`hsl(270, 45%, 95%)` להרמוניה.
- ה-RadialGauge (אם נחזיר אותו) — צבעי הסטופ של הגרדיינט יעודכנו ל-`hsl(265, 60%, 35%) → hsl(290, 70%, 60%)`.

### 5. בר הצ׳אט התחתון + InsightsSheet
- מסגרת ה-avatar הצפה: ההילה הסגולה כבר נכונה, רק נעמיק את הצל ל-`hsla(275, 65%, 25%, 0.45)`.
- כפתור Send בבר התחתון וב-InsightsSheet → גרדיינט מאסטר.
- בועיות המשתמש בצ׳אט → גרדיינט מאסטר עם טקסט לבן.
- צ׳יפס פעיל בתבליט הקטגוריות שב-Sheet → גרדיינט מאסטר במקום הצבע הקטגוריאלי הנוכחי.

### 6. קבצים שיתעדכנו
- `src/pages/IndexB.tsx` — כל הגרדיינטים, הצללים, וצבעי הטקסט המודגשים.
- `src/components/InsightsSheet.tsx` — בועיות משתמש, כפתור Send, צ׳יפסים פעילים.
- `src/index.css` — עדכון ה-keyframe `networth-shine` לגוונים סגולים מהפלטה החדשה.

### 7. תוצאה צפויה
מסך אחיד שבו הכרטיסיות, ה-CTAs, בר הצ׳אט והבועיות כולם "מדברים" באותה שפה ויזואלית של שחור עמוק שמתפזר לסגול עשיר — בדיוק כמו האווירה של כרטיס ה-Overview בתמונה. אין יותר קפיצות לציאן/אדום/כתום, והוורוד-זרחני יוחלף בסגול עמוק יוקרתי.
